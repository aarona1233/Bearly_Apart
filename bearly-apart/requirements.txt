# Bearly Apart — what each computer needs.
# Nothing here has to be installed by hand: run the setup script for your machine.
#
#   To USE the app, nothing: Windows runs "Bearly Apart Setup.exe", a Mac opens "Bearly Apart for Mac.zip",
#   Linux unpacks "Bearly Apart for Linux.tar.gz". The rest of this file is for building those (npm run release).
#   Your Linux PC .......... ./setup-linux.sh  (installs everything below, safe to re-run)
#   Your Windows PC ........ see START-HERE.md, "Building the downloads" (Node, Python, Developer Mode, rcodesign)

# --- Running from source on Linux (setup-linux.sh handles all of it) ---
nodejs>=22           # LTS from nodejs.org, installed to ~/.local (no sudo needed)
npm-packages         # from package-lock.json via `npm ci`: electron 44, @electron/packager, electron-winstaller
python3              # already on Debian/Ubuntu; used to zip the Mac app with its symlinks intact

# --- Optional on Linux ---
gnome-shell-extension-appindicator   # shows the 💗 tray icon on GNOME (needs sudo, then log out/in)

# --- Only for building the Mac app from Linux ---
rcodesign==0.29.0    # ad-hoc signs the Mac app; installed to ~/.local/bin by setup-linux.sh --build-tools
